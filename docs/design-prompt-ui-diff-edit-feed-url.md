# デザイン差分指示: 購読フィード編集ダイアログにURL欄を追加(#77)

Claude Design のチャットに送った変更指示。

```
購読フィード画面の「フィードを編集」ダイアログを変更してください。(1) 現在、ダイアログ最下部にある読み取り専用のURL表示(等幅・小さい文字)を削除し、代わりに「名称」と「取得間隔」の間に「URL」入力欄を追加する。ラベル・入力欄のスタイルは「名称」と同一(高さ40px、border-radius 8px、同じ枠線・背景・フォント)で、初期値は現在のフィードURL。(2) URLのエラー表示(不正なURL / 既に登録済み / RSSとして解析できない)を、URL欄の直下に赤(var(--err))の13px文字で出し分けて表示する。エラー時はURL欄の枠線も赤にする。文言は「URLの形式が正しくありません。http:// または https:// から始まるURLを入力してください。」「このフィードはすでに登録されています。」「RSS / Atom として解析できませんでした。」。(3) URL検証中は保存ボタンを無効状態にして、ラベルを「検証中…」にする。(4) 編集メニューの項目名を「名称・URL・取得間隔を編集」に変更する。他の画面・配色・レイアウトは変更しないこと。
```

DesignSync で `Deep Tracker.dc.html` を取得し、URL欄(名称と同一スタイル)・エラー表示(13px / `var(--err)`)・保存ボタンの「検証中…」・メニュー項目名が反映されていることを確認済み。
