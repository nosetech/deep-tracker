# Claude Designへの差分指示プロンプト: 設定画面の削除とテーマ切り替えボタン

[design-prompt-ui.md](./design-prompt-ui.md) の初回デザイン後に送った差分依頼です。単独では使わない。実際に送信した内容を、読みやすいよう改行して記録しています。

## 背景

設定（保存期間・サマリの実行周期・Slack通知・LAN公開）は**GUIから変更せず、YAML設定ファイルの編集のみ**とし、変更の反映はアプリの再起動で行う方針に決まったため、設定画面を削除した。テーマ切り替えは producer-desk のダッシュボードと同じ、画面右上の丸いアイコンボタンにした。

---

## ここからプロンプト

デザインの修正をお願いします。

(1) 設定画面を削除してください。設定(保存期間・サマリの実行周期・Slack通知・LAN公開・表示テーマ設定)はGUIから変更せず、すべてYAML設定ファイルの編集だけで行う方針にしたため、設定画面・設定のナビ項目・「設定は自動で保存されます」等の表示は不要です。ナビはサマリ/記事一覧/購読フィードの3項目にしてください(モバイルのボトムナビも3項目)。サイドバー下部にあるバージョンやデータ保存先(~/.deeptracker/...)などの設定ファイル前提の表記も削除してください。

(2) テーマ切り替えは、画面右上に丸いアイコンボタン1つを配置してください。仕様は、直径28px・border-radius 999px・1pxの控えめな枠線・背景はカード色・アイコンは15px、ホバーで背景と文字色が少し強くなる。ダークテーマ表示中は太陽アイコン(円+放射線のアウトライン)、ライトテーマ表示中は月アイコン(塗りつぶし)を表示し、クリックでライト/ダークを切り替える。従来の3択(システム/ライト/ダーク)は廃止し、初期表示はOSのテーマに従い、手動で切り替えたらその選択を優先する。aria-labelは「ライトモードに切り替え」「ダークモードに切り替え」。PCでは右上に常時見える位置(コンテンツ上部のスリムなヘッダー行の右端など)、モバイルでも画面右上に表示する。

(3) サマリ失敗時のメッセージなど、他の画面に設定画面への導線があれば削除してください。それ以外のデザインは変更しないでください。
