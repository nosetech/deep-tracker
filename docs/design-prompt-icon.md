# アイコン（ロゴ）のデザイン指示

Claude Design（`Deep Tracker Icons.dc.html`）で作成した。issue #70。

## 指示の要旨

- アプリ「Deep Tracker」のアイコン / favicon を提案する。サイドバーの現行ロゴ「DT」の置き換え。
- コンセプト: 「RSSの購読」と「深く追う」を連想させるシンボル。
- 16px・24px でも潰れないシンプルな形。ライト/ダーク両テーマのサイドバーで視認でき、favicon（小サイズ）でも識別できること。
- 複数案（ソナー / DTモノグラム / 蒸留 / 深層 / D＋記事）を出し、ダーク・ライトタイル、64/32/16px、タブでの見え方で比較する。

## 採用案

「1e D＋記事」。D の中に本文の行を並べ、中央の一行をアクセント色（アンバー `#f2c14e`）にして「抽出された要点」を表す。

- タイル: `#2b2d33`、角丸 14/64
- D と本文の行: `#f6f6f4`
- アクセントの行: `#f2c14e`

実装: `frontend/app/icon.svg`（マスター）、`favicon.ico`（16/32/48px）、`apple-icon.png`（180px）、サイドバーは `AppShell.tsx` のインライン SVG（タイルと行の色はテーマ変数 `--tx` / `--bg`）。
