# デザイン差分指示: ページの最大横幅の固定をやめ、ブラウザ幅に合わせて広げる(#105)

Claude Design のチャットに送った変更指示。

```
各画面の最大横幅の固定をやめ、ブラウザ幅に合わせて広げてください。モック上のプレビュー幅（PC 1280 など）に加え、広い画面（1920px・2560px相当）でも確認できるようにしてください。【変更】1. 記事一覧（max-width:920px）・購読フィード（max-width:1040px）・サマリ左カラム（max-width:760px）・読み込み中スケルトン（max-width:860px）の固定幅を外し、サイドバーを除いた領域の幅いっぱいに広げる（余白paddingは維持）。2. 超ワイド画面での間延び対策として、ページ全体の上限を1600pxにし、それ以降は左寄せのまま（中央寄せにしない）。3. サマリは2カラムのまま、左（サマリ本文）を伸縮（flex:1 1 560px、max-widthなし）、右の元記事プレビュー/サイドは現状の幅を維持。flex-wrapによる折り返しの挙動は変えない。4. 記事詳細は、タイトル・メタ情報・操作ボタンなど周辺要素を上限1600pxまで広げ、記事本文だけ38emのまま（行長は変更しない）左寄せにする。5. 記事の行・カードは、幅が広がってもタイトルの省略表示（text-overflow）と、タグ・日付の配置が自然に保たれるようにする。【変えないもの】モバイル（719px以下）とタブレット（999px以下）の既存レイアウト、配色、フォント、その他の画面。
```
