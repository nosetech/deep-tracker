# デザイン変更プロンプト: サマリの元記事プレビューパネル（#73）

Claude Design の「Deep Tracker.dc.html」に対する変更指示。

```
サマリ画面に「元記事プレビューパネル」を追加してください。現状は、サマリ内の元記事（.sum-src-open）を押すと記事詳細画面に遷移しますが、遷移せずサマリ画面内にプレビューを出します。既存のデザインのトークン・配色・角丸・フォントを踏襲してください。

【パネル内容】
ヘッダー: 「元記事」ラベル、右側に表示位置切り替えトグル（「右」「下」の2択のセグメントボタン。アイコン+aria-label、選択中を強調）と閉じるボタン（×）。
本体: 記事タイトル、フィード名・公開日時のメタ、本文（記事詳細画面の本文スタイルと同じ）、末尾に「外部サイトで開く」「記事画面で開く」の2つのリンク。パネル内は本文が長い場合スクロールします。

【選択中の元記事】
サマリ内の該当行をハイライト（背景を薄いアクセント色、左に2pxのアクセント線）。もう一度押すか×で閉じます。

【表示位置・デフォルトは右】
右側: サマリ本文の右隣に幅 420px のパネルを置き、画面高に合わせて sticky（上端はヘッダー直下）、枠線1px・角丸は既存カードと同じ。パネル表示中は右端のサマリ一覧サイドバーを非表示にして幅を確保します（閉じると元に戻る）。
下側: サマリ本文の直下に全幅（本文と同じ幅）で表示し、高さは最大 560px で内部スクロール。

【狭い画面（1180px未満・モバイル）】
「右」が選ばれていても下側表示にし、切り替えトグルは隠して×のみ表示します。

【状態】
読み込み中（スケルトンまたはスピナー）、取得失敗（エラー表示と再試行）、記事なしの各状態も既存のstatesの見た目で用意してください。ライト/ダーク両対応でお願いします。
```
