```
前提: 英語など日本語以外の記事は、取得時にAIが自動でタイトルと本文を日本語に翻訳します（取得1回あたりの件数に上限があり、上限を超えた記事や過去の記事は未翻訳のまま残ります）。原文は保持され、いつでも原文に切り替えられます。本文が長すぎる記事は先頭のみ翻訳します。

1) 記事詳細画面: 翻訳済みの記事は日本語を既定で表示し、タイトル下のアクション行（元記事を開く／既読にする／マーク）の近くに「翻訳済み」を示す小さなラベル（翻訳アイコン付き）と「原文を表示」の切替を置く。原文表示中は「翻訳を表示」に変わる。本文の途中までしか翻訳していない場合は、本文の末尾付近に「本文が長いため、先頭のみ翻訳しています（続きは原文を表示）」の注記を出す。
2) 記事詳細画面: 未翻訳の日本語以外の記事には、同じ位置に「日本語に翻訳」ボタンを出す。押すと「翻訳中…」（スピナー付き、ボタンは無効）になり、完了すると日本語表示に切り替わる。失敗時は「翻訳できませんでした」と「再試行」、利用制限に達した場合は「AIの利用制限に達しました。時間をおいて再試行してください」（解除予定時刻があれば表示）と「再試行」を、既存のエラー表示と同じトーンで本文の上に出す。失敗しても原文の本文はそのまま表示する。
3) サマリ画面の元記事プレビュー（右側パネル）: 記事詳細と同じく、翻訳済みなら日本語を既定で表示し、「翻訳済み・原文を表示」の切替を出す。未翻訳の日本語以外の記事には「日本語に翻訳」ボタンと翻訳中・失敗・利用制限の表示を出す（パネル幅に合わせたコンパクトな配置）。
4) 記事一覧: 翻訳済みの記事はタイトル・抜粋を日本語で表示し、行のメタ情報（フィード名・日時）の並びに「翻訳」を示す小さなバッジを付ける。一覧での原文切替は不要。未翻訳の日本語以外の記事には何も付けない。
5) デモ操作バーに、記事の翻訳状態（日本語の記事／翻訳済み／翻訳済み（先頭のみ）／未翻訳／翻訳中／翻訳失敗／利用制限）を切り替える操作を追加（デザイン確認用）。

サイドバーやフィード管理画面、設定画面の追加は不要です（設定はYAMLのみ）。
```
