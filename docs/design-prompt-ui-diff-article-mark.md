# デザイン差分指示: 記事のマーク（ブックマーク）(#124)

Claude のチャットに送った変更指示。

```
Deep Trackerのデザインに「記事のマーク（ブックマーク）」機能のUIを追加してください。既存のレイアウト・配色・コンポーネントの作りは変えず、以下だけを追加します。1) 記事一覧の各記事行に、マークのON/OFFを切り替えるアイコンボタン（ブックマーク形のアイコン。OFFは枠線のみ、ONは塗りつぶしでアクセント色）を追加。既読/未読の表示とは独立で、マークしても未読のまま、既読にしてもマークは外れない。2) 記事一覧の絞り込みに「マーク済みのみ」トグルを追加。既存の「未読のみ/すべて」とは独立した条件で、フィード・期間・キーワードと併用できる。3) 「マーク済みのみ」ON時にマーク済みが0件の空状態の文言「マーク済みの記事はありません」。「マーク済みのみ」表示中にマークを解除した記事は一覧から外れる。4) 記事詳細画面のヘッダー付近にも同じマーク切り替えボタンを追加。5) マーク切り替えの失敗時トースト、成功時の「元に戻す」付きトーストは既存の既読操作と同じ見た目。マークの種類は1種類のみで、サイドバーの件数バッジや専用ページは不要です。
```

Claude 側の結果:

- 記事一覧の行: 既読ボタンの左にブックマークアイコン。OFF は枠線のみ（`--tx3`）、ON はアクセント色（`--ac`）で塗りつぶし。PC は 30px、モバイルは 40×44px。
- 絞り込み: フィード・期間の隣に「マーク済みのみ」ボタン（高さ `ui.ctlS`、角丸7px）。ON は `--acSoft` 背景＋`--acLine` 枠＋`--ac` 文字。「条件をクリア」でも解除される。
- 空状態: 「マーク済みの記事はありません」と「「マーク済みのみ」を解除」ボタン。
- 記事詳細: 「元記事を開く」「既読にする」の並びに 36px 角のマークボタン（ON は `--acSoft` / `--acLine` / `--ac`）。
- トースト: 「マークしました」「マークを外しました」（元に戻す付き）、失敗時は「マークできませんでした。時間をおいて再度お試しください。」等。
- デモ操作バーに「マーク切り替えの結果（成功/失敗）」を追加（デザイン確認用。実装には不要）。
