# デザイン差分指示: サイドバーを折りたためるようにする(#113)

Claude Design のチャットに送った変更指示。

```
PC表示(720px以上)のサイドバーを折りたたみ可能にする変更をデザインに反映してください。(1)折りたたみボタン: サイドバー下部(「最終取得」の下)に配置。展開時は「サイドバーを模した矩形＋左向き矢印のアイコン(24x24, 線1.7px, path: M9 4v16 と M16 10l-2 2 2 2)」と「折りたたむ」ラベルの横長ボタン(高さ34px、文字12.5px、色var(--tx2))。折りたたみ時はアイコンのみ・矢印は右向き(M14 10l2 2-2 2)で、title「常に表示する」。(2)折りたたみ時: サイドバー幅68px、ナビはアイコンのみ中央寄せ(高さ38px)、ラベル・「最終取得」・取得エラー文言は非表示。アクティブ項目は展開時と同じ背景var(--surface2)。(3)未読バッジは折りたたみ時は件数を出さず、アイコン右上に8pxのドット(var(--ac)、周囲に2pxのvar(--surface)の縁取り)。取得エラーはアイコン右上に8pxのドット(var(--err)、同じ縁取り)。未読とエラーが同時にある項目は別項目なので重ならない。(4)ホバーで一時展開(peek): 折りたたみ中にサイドバーへマウスを乗せると140ms後に232pxへ広がり、本文は押し広げず上に重なる。右に影(box-shadow: 8px 0 28px rgba(0,0,0,.18)、ダークは.45)、離すと220ms後に戻る。幅は0.2s easeで変化。展開中は通常の展開時と同じ表示(ラベル・バッジ件数・最終取得)。折りたたみ状態(68px)と、ホバーで一時展開した状態(232px、本文に重なる)の両方を、ライト・ダークでモックに見えるようにしてください。モバイルは変更しない。他の画面・配色は変更しないこと。
```
