# デザイン差分指示: PC表示を全幅ヘッダー＋サイドバー構成にする(#109)

Claude Design のチャットに送った変更指示。

```
PC表示(720px以上)の画面構成を変更してください。画面上部に全幅のヘッダーを置き、その下にサイドバーと各画面を横に並べる構成にする。ヘッダー: 高さ52px、背景var(--surface)、下に1px var(--line)の境界線。左にアプリ名(マーク24px+「Deep Tracker」15px太字+直下にバージョンv0.1.0、現状どおり絶対配置で有無により位置が動かない)、左余白は16px。右端にテーマ切り替えボタン(現状の28pxの丸ボタン)、右余白16px。サイドバーからアプリ名ブロックを取り除き、ナビゲーションと下部の「最終取得」「取得エラー」のみにする。サイドバーは幅232px・border-rightはそのまま維持し、ヘッダーの下から始まる。サイドバー上部のpaddingは18pxから12px程度に調整する。現状の44pxのデスクトップヘッダー(テーマ切り替えのみ)は廃止してヘッダーに統合する。モバイル(720px未満)は変更しない。他の画面・配色は変更しないこと。
```

DesignSync で `Deep Tracker.dc.html` を取得し、`<header>` が高さ52px・`padding:0 16px`・`background:var(--surface)`・`border-bottom:1px solid var(--line)`、サイドバーの上paddingが12pxになっていることを確認済み。
