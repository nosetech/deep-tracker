# デザイン差分指示: サイドバーにバージョン番号を表示(#80)

Claude Design のチャットに送った変更指示。

```
サイドバー上部のブランド表示(DTマーク+「Deep Tracker」)を変更してください。アプリ名「Deep Tracker」の直下に、バージョン番号を小さい補助テキストで「v0.1.0」の形式で追加する。左端はアプリ名の文字に揃え、サイズは11px、等幅フォント、色は既存の補助テキスト色(薄いグレー系)を使い、ライト/ダーク両テーマでコントラストが保たれること。サイドバー幅に収まり折り返さないこと。モバイルのヘッダーにはバージョンを表示しない。instance(設定値)は表示しない。バージョンが取得できない場合は何も表示せず、アプリ名の位置は変えない。他の画面・配色・レイアウトは変更しないこと。
```

DesignSync で `Deep Tracker.dc.html` を取得し、アプリ名の直下に `position:absolute; top:100%; margin-top:1px`、IBM Plex Mono 11px、行高1.2、色 `var(--tx3)` で表示されることを確認済み。モバイルヘッダーには表示しない。

## 追補: モバイルのヘッダーにもアプリ名とバージョンを表示する

モバイルでもアプリ名を表示するよう、Claude Design 側でデザインを修正した（ヘッダー左にマーク22px + 「Deep Tracker」13px + その下に `v0.1.0` 10px / IBM Plex Mono / `var(--tx3)`、画面タイトルは中央、テーマ切替は右）。上の指示プロンプトの「モバイルのヘッダーにはバージョンを表示しない」は、この追補で置き換わる。

## 追補: 記事詳細のモバイルヘッダーはアプリ名の代わりに「戻る」を表示する

Claude Design 側で、モバイルの記事詳細ではヘッダー左のアプリ名(マーク+名称+バージョン)を出さず、代わりに戻る(‹)ボタン(44×44px、アイコン20px、`var(--tx)`)を表示するよう修正した。戻り先は記事一覧(サマリから開いた場合はサマリ)。
