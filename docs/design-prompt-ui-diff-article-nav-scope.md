# デザイン差分指示: 記事詳細の前後記事を「未読のみ／すべて」で切り替える(#106)

Claude Design のチャットに送った変更指示。

```
記事詳細画面の下部「← 新しい記事」「古い記事 →」リンクに、前後記事の対象を切り替えるトグルを追加してください。【変更】1. 前後記事リンク（2列グリッド）の上、区切り線（border-top）の直下の右寄せに、既存の記事一覧の「未読のみ／すべて」セグメント（背景・角丸6px・13px）と同じスタイルの小さなセグメント切替「未読のみ｜すべて」を置く。既定は「未読のみ」。左に補助ラベル「前後の記事」（11.5px・--tx3）。2. 「未読のみ」で前後に未読の記事がない側は、ボタンの代わりに破線枠の控えめな空表示「未読の記事はありません」（11.5px・--tx3）を出す。その横または下に「すべて」に切り替えるテキストリンク（--ac色）を添える。両側とも未読がない場合も同様。3.「すべて」のときは従来どおり、端の側は何も表示しない。4. モバイルでは、セグメントを前後ボタンの上に全幅で置く。5. デモ用に、モックの記事詳細で未読のみ状態と、未読なしの空表示状態を確認できるようにする。【変えないもの】配色、フォント、他の画面、既存の前後ボタンの見た目。
```

Claude Design 側の結果: 空表示のリンク文言は「すべての記事を表示」、セグメントの高さは `ui.ctlS`。
